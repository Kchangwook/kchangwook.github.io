# 블로그 게시글 작성 규칙

사용자가 블로그 게시글 작성을 요청하면 다음 규칙을 반드시 따른다.

1. **카테고리 및 게시글 자동 작성**
   - 주제에 맞는 `categories`와 `tags`를 스스로 판단해 지정한다.
   - **제목은 담백하게 핵심 주제만 작성한다.** (`완벽 정리`, `총정리`, 긴 부제 같은 수식어를 붙이지 않는다. 예: `로드밸런서`)
   - 기존 게시글(`_posts/`)의 Jekyll Chirpy 테마 형식(YAML frontmatter, `mermaid: true`, 표, 코드 블록, `{: .prompt-info }` / `{: .prompt-tip }` / `{: .prompt-warning }` 콜아웃 등)에 맞춰 `_posts/YYYY-MM-DD-<slug>.md` 파일을 직접 생성한다.
2. **채팅 응답에 실제 화면처럼 전체 미리보기 출력**
   - 게시글을 작성하거나 수정한 뒤에는 요약만 하지 말고, 사용자가 바로 읽고 피드백할 수 있도록 **실제 블로그 화면에 보이는 것과 동일한 형태로 게시글 전체 내용(제목, 카테고리/태그, 본문, 다이어그램, 표, 코드 블록 등)을 채팅 응답에 그대로 출력**한다.
   - 채팅 미리보기에서는 `{: .prompt-... }` 같은 Kramdown 전용 구문은 노출하지 않고 깔끔한 인용구(콜아웃) 형태로 렌더링해 보여준다.
